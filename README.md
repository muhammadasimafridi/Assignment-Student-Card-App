# 🎓 Student Card App

A simple and interactive **Student Card Generator Web App** built using HTML, CSS, and JavaScript. This app allows users to enter student details and dynamically generate a styled card displaying the information.

---

## 🚀 Features

* 📝 **User Input Form** – Enter student name, age, class, and image URL
* 🖼️ **Dynamic Card Creation** – Generates a student card instantly
* 📸 **Image Display** – Shows student image from provided URL
* ⚡ **Real-time UI Update** – Card appears without page reload
* 🧹 **Auto Clear Fields** – Input fields reset after submission

---

## 🧠 Concepts Used

* DOM Manipulation
* Event Handling (Click Events)
* Dynamic Element Creation
* Template Rendering (HTML content generation)
* Form Handling

---

## 📂 Project Structure

* `HTML` → Structure and input fields
* `CSS` → Styling for card layout
* `JavaScript` → Logic for creating and displaying cards

---

## 🎯 How It Works

1. User enters student details in input fields
2. Clicks the **Create** button
3. A new student card is generated dynamically
4. The card displays:

   * Student Name
   * Age
   * Class
   * Image (from URL)
5. Input fields are cleared for the next entry
